Features

⭐

Full GUI

Clean dark-themed interface with real-time stats, animated progress bar, and asset tree view.

⚡

Multi-threaded

Downloads assets in parallel with configurable worker threads (1-20).

🌐

Multi-page Crawl

Follows same-domain links up to a configurable depth to clone entire sections of a site.

📝

URL Rewriting

Converts all asset URLs to local relative paths. Parses and rewrites CSS url() and @import references.

📦

Export as ZIP

Package your cloned site into a single .zip file for sharing or archiving.

📁

CLI Mode

Run headlessly from a terminal, script, or CI pipeline. Same engine, no GUI.

📊

Live Stats

Track pages, assets, download size, and speed in real-time during the clone.

⚙

Configurable

Toggle images, CSS, JS, fonts. Set custom User-Agent, proxy, request delay, and more.

🔄

Session Memory

Remembers your settings, window position, and recent URLs between sessions.

Use Cases

🏗

Platform Migration

Rebuild a site from WordPress, Webflow, or Squarespace into static HTML you control.

💾

Offline Reference

Save documentation, tutorials, or reference sites for offline access — no internet needed.

📱

Design Research

Inspect how production sites structure their HTML, CSS, and assets by working with real code.

📤

Archival

Preserve a snapshot of a site before it changes or disappears. Full offline copy with all assets.

⛓

Recover Lost Source

Site is live but the original repo is gone? The developer left? Get the code back as a static copy.

🔧

Rapid Prototyping

Clone a landing page or component library as a starting point for your own project.

How to Use

1

Enter URL

Paste any website URL or press Ctrl+V to grab from clipboard.

2

Configure

Choose output folder. Toggle asset types, set crawl depth, adjust workers.

3

Click Clone

Watch real-time progress as assets download in parallel.

4

Open Site

Click Open Site to view your fully-functional offline copy.
