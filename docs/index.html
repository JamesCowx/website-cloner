Capabilities

Everything you need

A complete toolkit for cloning and preserving websites — from asset discovery to offline-ready output.

🎨

Full GUI

Polished dark-themed desktop interface with real-time stats, animated progress bar, and live asset tree. No terminal needed.

⚡

Parallel Downloads

Multi-threaded engine with 1-20 configurable workers. Images, CSS, JS, and fonts download simultaneously at maximum speed.

🌐

Deep Crawling

Follow same-domain links up to configurable depth. Clone entire documentation sites, blogs, or product pages in one pass.

📝

CSS Rewriting

Parses url() and @import rules for nested assets, then rewrites every path to local equivalents automatically.

📦

ZIP Export

One-click packaging of the entire cloned site into a single .zip archive for sharing, backup, or long-term archival.

⌨

Headless CLI

Full command-line mode for scripting: python cloner.py https://site.com --headless -o ./out -d 2

🛡

Rate Limiting

Configurable request delay, custom User-Agent string, and HTTP proxy support to avoid rate limits and blocks.

💾

Session Memory

Remembers all settings, window position, and recent URLs between sessions. Pick up exactly where you left off.

FAQ

Common questions

Website Cloner is a tool. Respect copyright, terms of service, and robots.txt. Do not use it for phishing, impersonation, or passing off someone else's work as your own. It is intended for legitimate purposes: platform migration, offline reference, design research, and recovering your own lost source code.

No. Website Cloner downloads static HTML and assets. JavaScript is not executed, SPAs are not pre-rendered, and there is no headless browser. For JS-heavy sites, the raw scripts will be present in the output but dynamic content won't be pre-rendered.

If a site has aggressive rate limiting, use the Delay setting (0.5s-2s), set a custom User-Agent string, or route through a Proxy. Sites behind Cloudflare or Akamai may require additional tools beyond Website Cloner.

The .exe is Windows-only, but the Python source runs on macOS and Linux with Python 3.9+. Clone the repo and run with: python cloner.py. Same features, same engine, no GUI differences.
