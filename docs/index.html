Capabilities

Everything you need

From asset discovery to offline-ready output — a complete toolkit for cloning websites.

🎨

Full GUI

Dark-themed polished interface with real-time stats, animated progress bar, and live asset tree. No terminal needed.

⚡

Parallel Downloads

Multi-threaded with 1-20 configurable workers. Images, CSS, JS, and fonts download simultaneously at max speed.

🌐

Deep Crawl

Follow same-domain links up to configurable depth. Clone entire docs sites, blogs, or product pages in one go.

📝

CSS Rewriting

Parses url() and @import rules to discover nested assets, then rewrites all paths to local equivalents.

📦

ZIP Export

One-click packaging of the entire cloned site into a single .zip archive for sharing, backup, or archival.

⌨

Headless CLI

Run from terminal or scripts: python cloner.py https://site.com --headless -o ./out

🛡

Rate Limiting

Configurable request delay, custom User-Agent, and HTTP proxy support to avoid getting blocked.

💾

Session Memory

Remembers all settings, window position, and recent URLs between sessions. Pick up where you left off.
